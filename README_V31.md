# Liza V31

Исправлен маршрутизатор команд во время активной записи.

Команды `Лиза добавить @username` и `Лиза записать @username` теперь перехватываются до AI. Также во время активной записи они распознаются без обращения `Лиза`: `добавить @username` и `записать @username`.

Ручная запись работает по username без Telegram ID.
