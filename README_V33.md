# Liza V33 — команды без приставки «Лиза»

В этой версии все зарегистрированные текстовые команды можно выполнять напрямую в сообщении чата, без обязательного обращения `Лиза`.

Примеры:
- `настройки`
- `помощь`
- `пыхнуть`
- `заварить`
- `стата 7`
- `бан @user причина`
- `мут @user 30м причина`
- `запись 2 текст конкурса`
- `стоп запись`

Обычные сообщения, которые не совпадают с командой, продолжают обрабатываться по прежней логике. Обращение `Лиза ...` также сохранено для совместимости и обычного AI-диалога.

Архив плоский: все файлы находятся в корне ZIP.
