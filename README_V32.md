# Лиза — V32

Добавлены две отдельные мини-игры с постоянной статистикой в SQLite:

- `Пыхнуть` — сигареты, отдельный счётчик пользователя и cooldown 1 час.
- `Заварить` — кофе, отдельный счётчик пользователя и cooldown 1 час.
- `стата 7` — статистика за последние 7 дней.
- `стата 3 дня` — статистика за последние 3 дня.
- `стата вся` — статистика за всё время.

Статистика ведётся отдельно для каждого группового/личного чата. В `стата` выводятся две таблицы: сигареты и кофе, по убыванию количества.

Все события сохраняются в `minigame_events` в SQLite, поэтому данные не теряются после перезапуска бота.
