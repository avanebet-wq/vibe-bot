# Mini App интеграция для «Лизы»

Этот пакет содержит только файлы, которые нужно заменить/добавить в репозиторий `vibe-bot`.

## Файлы

- `runtime.py` — вместо старого dummy HTTP server запускает Mini App/API server.
- `settings.py` — кнопка «Удобное создание кнопок» в разделе URL-кнопок и обработчики специальных кнопок.
- `settings_ui.py` — Web App-кнопка в окне URL-кнопок.
- `miniapp.py` — API, проверка Telegram `initData`, проверка администратора и сохранение кнопок в настройки повторяющейся публикации.
- `miniapp/index.html` — готовый интерфейс конструктора, адаптированный под `chat_id + post_id`.

## Что НЕ нужно добавлять

`server_example.py` из исходного конструктора сюда не нужен: он написан под aiohttp/aiogram 3, а «Лиза» работает на pyTelegramBotAPI.

## Railway

Новых секретов добавлять не требуется.

Не добавляйте BOT_TOKEN/OpenRouter ключи в код. Бот продолжает брать их из существующих Railway Variables.

Важное условие: в @BotFather должен быть настроен **Main Mini App** этого бота на ваш Railway-домен. Кнопка из группового меню открывает Main Mini App через Telegram direct link `https://t.me/<BOT_USERNAME>?startapp=...`; это нужно, потому что `web_app`-кнопки inline-клавиатуры доступны только в личном чате с ботом.

Переменная `MINIAPP_BASE_URL` не требуется: сам Mini App обслуживается Railway по `PORT`, а запуск из Telegram идёт через Main Mini App.

## Как работает

Настройки → Повторяющиеся сообщения → публикация → URL-кнопки → «Удобное создание кнопок».

Поскольку повторяющаяся публикация ещё не имеет Telegram `message_id`, конструктор привязывается к `chat_id + post_id`. После сохранения кнопки записываются в шаблон публикации, а планировщик применяет их при каждой отправке.

Сервер каждого запроса проверяет Telegram `initData` через HMAC и повторно проверяет, что пользователь является администратором целевого чата.

## После загрузки

1. Дождаться успешного deploy в Railway.
2. Открыть `https://vibe-bot-production-fbd5.up.railway.app/` — должно остаться `Liza is alive!`.
3. Открыть `https://vibe-bot-production-fbd5.up.railway.app/app/` — должна открыться страница конструктора. При прямом открытии в браузере сохранение не сработает без Telegram `initData`; рабочий запуск выполняется из Telegram.
4. В Telegram открыть настройки Лизы → повторяющееся сообщение → URL-кнопки.
5. Нажать «Удобное создание кнопок».
6. Создать кнопку и сохранить.
7. Сделать предпросмотр/дождаться публикации и проверить клавиатуру.
