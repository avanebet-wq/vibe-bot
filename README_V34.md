# Liza V34 — расширенное меню настроек

V34 расширяет существующее меню «настройки» полноценной панелью управления поведением Лизы.

Основные разделы:
- 👅 Ответы и активность: всем / только при обращении / полная тишина, автоактивность, уровень вмешательства и сон.
- 🧠 Память: включение/выключение запоминания и очистка памяти текущего чата.
- 🎭 Характер: просмотр текущих параметров характера.
- 🛡️ Модерация: быстрые переключатели удаления нарушений и защиты администраторов.
- 🎮 Развлечения: мини-игры и автоистории.
- ⚙️ Функции чата: стилистические режимы и переход к расширенным настройкам.
- 📊 Статус: единый обзор текущих состояний.
- 🔄 Сброс: подтверждаемый возврат настроек поведения Лизы к безопасным значениям.

Все кнопки меню используют inline-клавиатуры и редактируют существующее сообщение, чтобы не засорять историю чата. Это соответствует рекомендациям Telegram для многоуровневых настроек и меню.

Архив V34 намеренно не содержит runtime-файлы базы данных.


## V34.1 — игра «Выпить»
- Команда: `выпить` (также работает `выпить`).
- Случайно выбирается одно из 9 названий Revo с фруктовым эмодзи.
- Множитель выбирается взвешенно: низкие значения выпадают значительно чаще, 5x — 0.2%.
- Объём рассчитывается по формуле `1 + множитель`, поэтому пример `1.5x = 2.5 л` соблюдается.
- Каждый результат сохраняется отдельно по `chat_id + user_id`, вместе с Revo, множителем и объёмом.
- В `стата` добавлена статистика игры «Выпить».
