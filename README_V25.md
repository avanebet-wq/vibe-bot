# V25 — исправление приглашений конкурса

В V25 кнопка «➕ Пригласить людей» больше не создаёт персональные invite-ссылки через Telegram API.

- Используется уже существующая ссылка группы (публичный `@username` или доступная primary invite link).
- По нажатию открывается штатное Telegram-окно `t.me/share/url` для отправки приглашения.
- Прямые добавления пользователей в группу учитываются по service-сообщениям `new_chat_members`: отправитель такого сообщения считается пригласившим.
- Один и тот же пользователь не засчитывается одному приглашавшему повторно.
- Входы по общей ссылке не приписываются случайному участнику, поскольку без персональной invite-ссылки Telegram не передаёт боту информацию о том, кто поделился ссылкой.
- Ошибка «Не удалось создать приглашение. Проверь права Лизы администратора» из-за `create_chat_invite_link` устранена.
