# Лиза v20

## Что изменено

- v13: офлайн smoke-тесты, проверка связности модулей.
- v14: память и контекст ИИ стали более устойчивыми; факты пользователя ограничены и отделены от истории сообщений.
- v15: длинные диалоги используют структурированный контекст, память и профиль чата.
- v16: добавлены постоянные цели/задачи как фундамент будущих напоминаний.
- v17: настройки характера теперь могут отличаться по чатам.
- v18: добавлен подключаемый plugin registry через `LIZA_PLUGINS`.
- v19: Mini App получил защищённый `/api/dashboard` с состоянием, статистикой, модерацией, характером и настроением.
- v20: резервные копии SQLite, lifecycle hooks, graceful shutdown, health state, реальные migration tables, усиленные HTTP headers, очистка архива от `__pycache__`.

## Совместимость

Старое JSON-хранилище и существующие Telegram-команды сохраняются. Новые normalized tables используются как расширение и не удаляют старые ключи.

## Переменные окружения

`BOT_TOKEN`, `GROQ_API_KEY` — обязательные для запуска.
`LIZA_PLUGINS` — список plugin-модулей через запятую.
`LIZA_BACKUP_DIR` — каталог резервных копий SQLite.
`LIZA_BACKUP_KEEP` — количество сохраняемых backup-файлов.
`PORT` — порт Mini App/health endpoint.
