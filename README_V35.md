# Liza V35 — игра «Выпить»

Добавлена новая мини-игра `выпить`.

## Как работает
- Пользователь пишет `выпить` или `выпить`.
- Лиза случайно выбирает одно из названий Revo и добавляет ассоциирующийся фруктовый эмодзи.
- Множитель выбирается взвешенно от `0.5x` до `5x`: маленькие значения выпадают чаще, а `5x` — крайне редко.
- Объём: `1 + множитель` литра. Поэтому `1.5x = 2.5 л`, а максимальные `5x = 6 л`.
- Каждый результат записывается в отдельную таблицу `drink_game_events` по сочетанию `chat_id + user_id`.
- Сохраняются пользователь, название Revo, фруктовый эмодзи, множитель, объём и время результата.
- Команда `стата` показывает накопительную статистику «Выпить» по пользователям.
- Отдельного искусственного кулдауна для этой игры нет: каждая команда создаёт новый результат.

## Вероятности
`0.5x — 22%`, `0.7x — 28%`, `0.9x — 20%`, `1.0x — 12%`, `1.2x — 7%`, `1.5x — 5%`, `2.0x — 3%`, `2.5x — 1.5%`, `3.0x — 0.8%`, `4.0x — 0.5%`, `5.0x — 0.2%`.

Всего: 100%.
