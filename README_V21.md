# Лиза V21 — конкурсная запись

Добавлена команда конкурса/записи:

`запись 2 текст конкурса`

- Команда доступна администраторам группы.
- Лиза сразу публикует текст конкурса с кнопками `➕ Добавить людей` и `📝 Записаться`.
- Кнопка `Добавить людей` создаёт персональную Telegram invite-ссылку участника.
- Приход людей по персональной ссылке засчитывается пригласившему.
- Кнопка `Записаться` проверяет наличие username и требуемое количество приглашённых людей.
- Участник без username получает сообщение с просьбой создать username.
- Список записавшихся выводится с нумерацией и `@username`.
- Публикация повторяется каждые 60 секунд до команды `стоп запись`.
- Пока запись активна, обычные сообщения в группе не вызывают ответы Лизы и не передаются в AI. Исключение — команда администратора `стоп запись`.
- Состояние записи хранится в SQLite и переживает перезапуск контейнера.

Для создания invite-ссылок Лиза должна быть администратором группы с правом приглашать пользователей.
