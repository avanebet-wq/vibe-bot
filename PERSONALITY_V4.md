# Liza personality system — v4

Added configurable personality parameters on a 0–100 scale:
- humor
- sarcasm
- friendliness
- rudeness
- seriousness
- verbosity

The AI receives a compact style instruction on each request. The existing normal
and angry prompts remain active. Serious questions are explicitly protected from
excessive joking. Defaults are ready for later per-chat settings/UI integration.
