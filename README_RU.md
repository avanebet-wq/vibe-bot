# Лиза — VIBE

## Переменные Railway
- `BOT_TOKEN` — токен Telegram-бота от @BotFather.
- `OPENROUTER_KEY` — API-ключ OpenRouter.
- `LOG_CHAT_ID` — необязательный ID чата/канала для логов модерации.
- `PORT` — Railway задаёт автоматически.

## Доступ
Лиза не использует whitelist групп или список пользователей-владельцев. Она работает в любой группе/супергруппе, куда её добавили. Административные права определяются рангами Telegram-чата: создатель — 5 ранг.

## Основные Iris-style команды
Модерация: `+Модер`, `Повысить`, `Понизить`, `Разжаловать`, `Кто админ`, `Кто назначил`, `Модер лог`, `Варн`, `Варны`, `Варнлист`, `Мут`, `Муты`, `Проверить мут`, `Бан`, `Разбан`, `Причина`, `Кик`, `Кик тихо`, `Амнистия`.

Доступ команд: `Доступ команд`, `Мой доступ команд`, `Дк команда 0-6`, `+Дк`, `-Дк`, `+Лдк`, `-Лдк`, `Все лдк`, `Сброс команд`, `Сброс дк`, `Сброс всех лдк`, `Сброс лдк`.

Команды поддерживают префиксы `!`, `.`, `/` и обращение `Лиза`.
