# Лиза — версия в стиле Shmalala

Полная переработка бота под тон и структуру команд `shmalala.com/help`: обращение
по имени («Лиза, …»), лёгкий разговорный стиль ответов, статистика с настоящими
графиками и истории «для разнообразия».

## Что изменилось по сравнению со старой версией

- **Модерация**: оставлены только баны, муты и предупреждения (варны).
  Локальная система рангов (младший/старший модератор, администратор, создатель),
  система доступа команд (ДК) и вся экономика («ириски») полностью убраны.
  Право модерировать теперь определяется напрямую через Telegram
  (пользователь должен быть администратором чата) — отдельной системы прав внутри бота больше нет.
- **Тон и /help**: справка и все ответы переписаны в духе Shmalala — короче,
  живее, с обращением «Лиза, …» вместо служебных префиксов `!`/`.`/`/`.
- **Статистика**: `Лиза, статистика` строит настоящий PNG-график
  (matplotlib) — динамика сообщений по дням и топ участников чата,
  а не текстовую сводку.
- **Истории**: у Лизы есть набор коротких историй. Она может рассказать
  историю по запросу или, если включён режим «истории», иногда вставлять
  их сама в разговор — как это делает Shmalala.

## Переменные окружения

- `BOT_TOKEN` — токен бота от `@BotFather`. Обязателен.
- `OPENROUTER_KEY` — ключ (или несколько через запятую) для AI-ответов.
- `LOG_CHAT_ID` — необязательный чат/канал для логов.
- `PORT` — порт HTTP keep-alive сервера (для Railway/Render и т.п.).

## Установка

```bash
pip install -r requirements.txt
python main.py
```

Добавьте бота в группу и выдайте права администратора (бан/мут/удаление сообщений),
иначе модерационные команды будут отвечать ошибкой прав.

## Команды

Полный список — в тексте `Лиза, помощь` (см. `help.py`). Кратко:

### Модерация (только для админов чата)
- `Лиза, бан @user причина`, `Лиза, разбан @user`, `Лиза, банлист`
- `Лиза, мут @user 30м причина`, `Лиза, размут @user`, `Лиза, мутлист`
- `Лиза, варн @user причина`, `Лиза, снять варн @user`,
  `Лиза, мои варны`, `Лиза, варны @user`

По умолчанию 3 предупреждения → автоматический мут на час
(настраивается в `config.py`: `DEFAULT_WARN_LIMIT`, `DEFAULT_WARN_ACTION`).

### Статистика
- `Лиза, статистика` / `Лиза, что с чатом?` — картинка с графиками активности.

### Истории
- `Лиза, расскажи историю`
- `Лиза, включи истории` / `Лиза, отключи истории`

Тексты историй лежат в `stories.py` (список `STORIES`) — их легко
дополнить или заменить своими.

### Настроение и активность
- `Лиза, не спамь` / `Лиза, активнее`
- `Лиза, включи автоактивность` / `Лиза, отключи автоактивность`
- `Лиза, отключись` / `Лиза, включись`
- `Лиза, будь вежлива` / `Лиза, матерись`
- `Лиза, разозлись` / `Лиза, успокойся`

### AI-общение
Обращение по имени или ответ на сообщение Лизы включает обычный AI-диалог
(`ai.py`, через OpenRouter). Нужен `OPENROUTER_KEY`.

## Структура проекта

```
config.py      — переменные окружения, промпты, константы
database.py    — простое key/value хранилище на SQLite
runtime.py     — инициализация бота, keep-alive сервер
utils.py       — настройки чата, парсинг длительности, поиск цели команды
moderation.py  — баны, муты, варны
stats.py       — учёт сообщений + генерация графика (matplotlib)
stories.py     — истории
mood.py        — активность/сон/вежливость/злость
ai.py          — обращение к OpenRouter
help.py        — текст справки
handlers.py    — разбор сообщений и маршрутизация команд
main.py        — точка входа
```

## Что было сознательно убрано

Ранги модераторов, доступ команд (ДК), экономика (ириски, бонусы, переводы),
профили/анкеты, массовые упоминания, сетка чатов, наследование, игры
(кости, слова, крокодил и т.п.). Это была осознанная «зачистка» под задачу:
survive только модерация первого уровня (баны/муты/варны) + функции в духе
Shmalala (тон, статистика с графиками, истории).
