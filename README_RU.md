# Лиза — VIBE

Лиза — Telegram-бот для управления группами и супергруппами. README ниже является **полным справочником функций текущей Lite-сборки**: для каждой группы указано, что делает команда, как её вызвать и какие права/условия нужны.

> **Важно:** Лиза не использует whitelist групп. После добавления в группу она работает в любом чате, где Telegram разрешает ей выполнять соответствующее действие. Для модерации Лизе нужны права администратора Telegram.
>
> **Стиль ответов:** Лиза отвечает без декоративного префикса «💗 Лиза» и старается объяснять результат, ошибку и следующий шаг.

---

## 1. Установка и запуск

### Переменные окружения

- `BOT_TOKEN` — токен бота от `@BotFather`. **Обязателен.**
- `OPENROUTER_KEY` — ключ OpenRouter для AI-ответов. Нужен только для AI-функций.
- `LOG_CHAT_ID` — необязательный ID чата/канала для служебных логов.
- `PORT` — порт HTTP-сервера; Railway обычно задаёт его автоматически.

### Добавление в группу

`/start` в личных сообщениях — показывает кнопку добавления Лизы в группу.

После добавления Лиза сообщает, какие права администратора ей необходимы. Если права недостаточны, она не пытается выполнять опасное действие молча, а сообщает, какое разрешение требуется.

# 2. Быстрая помощь

### `Помощь`
Показывает главное меню команд.

### `Команды`
Список основных команд Лизы.

### `Команды Лиза`
Расширенная подсказка по возможностям.

### `Лиза помощь`
То же меню помощи в форме обращения к боту.

### Разделы помощи

- `Помощь модерация` — баны, муты, варны, кики, ранги и логи.
- `Помощь экономика` — баланс, бонусы и переводы.
- `Помощь статистика` — активность и статистика.
- `Помощь профиль` — анкета, ник, звание, город и другие поля.
- `Помощь настройки` — настройки чата и автоматизации.

### Формат команд

Большинство команд можно писать с префиксом `!`, `.`, `/` или через обращение `Лиза`.

Примеры:

```text
Бан @user причина
!бан @user причина
/бан @user причина
Лиза, бан @user причина
```

# 3. Модераторы и ранги

Локальные ранги Лизы:

1. **Младший модератор**
2. **Старший модератор**
3. **Младший администратор**
4. **Старший администратор**
5. **Создатель**

Создатель Telegram-чата определяется по статусу `creator` и защищён от обычного снятия полномочий.

### Назначение

`+Модер` — назначить участника младшим модератором.

`+Модер 2 @user` — назначить старшим модератором.

`+Модер 3 @user` — назначить младшим администратором.

`+Модер 4 @user` — назначить старшим администратором.

`+Модер 5 @user` — назначить создателем Лизы.

`+Админ @user` — назначение административного уровня.

Также поддерживаются компактные варианты `!!модер`, `!!!модер`, `!!!!модер`.

### Изменение ранга

`Повысить @user` — поднять ранг на один уровень.

`Понизить @user` — опустить ранг на один уровень.

`Разжаловать @user` — снять локальные полномочия.

`Снять @user` — снять полномочия модератора/администратора.

### Информация

`Кто админ` — список администраторов и их локальных рангов.

`Кто назначил @user` — кто назначил пользователя и на какой ранг.

`Модер лог` — журнал изменений полномочий.

`Модер лог от @user` — журнал назначений от конкретного пользователя.

`Мой модер лог` — история изменений, связанных с вами.

`Твой модер лог @user` — история рангов конкретного пользователя.

`Админы` / `Кто модер` / `Модераторы` — список текущих модераторов.

`Права рангов` — какие действия доступны каждому рангу.

# 4. Передача и восстановление управления

`Снимаю полномочия` — добровольно отказаться от своего локального ранга.

`Ухожу в отставку` — аналогичная команда.

`Разжаловать меня` — снять свои полномочия.

`Снять вышедших` — убрать из списка модераторов пользователей, покинувших чат.

`Снять всех` — массово снять локальные полномочия с защищёнными исключениями.

`Восстановить создателя` — восстановить локальную запись создателя, если она потерялась.

`Передать создателя` / `Передать владельца` — передача управления в предусмотренном сценарии.

> Эти команды требуют повышенных прав. Лиза не должна позволять обычному участнику получить административный ранг.

`Созвать всех текст` — то же в более естественной форме.

`Тегнуть всех текст` — альтернативная форма.

`Упомянуть всех текст` — альтернативная форма.

`Массовое упоминание текст` — явная форма.

`Созвать онлайн текст` — упомянуть только активных/онлайн участников.

Лиза ограничивает размер массового списка, чтобы не создавать чрезмерный спам и не превышать ограничения Telegram.

---

# 21. Сетка чатов

Сетка — функции управления несколькими связанными чатами.

`Чаты` / `Сетка чаты` — список подключённых чатов.

`+Сетка` — подключить чат.

`-Сетка` — отключить чат.

`Сетка` / `Сетка статус` / `Сетка инфо` — состояние сетки.

`Сетка модеры` — модераторы сетки.

`+Глмодер @user` / `-Глмодер @user` — добавить/удалить глобального модератора.

`+Гладмин @user` / `-Гладмин @user` — глобальный администратор.

`Глобан @user` — глобальный бан.

`Глоразбан @user` — снять глобальный бан.

`Сетка баны` — список глобальных банов.

`Сетка кик @user` — удалить пользователя из подключённых чатов по доступному сценарию.

Все сетевые действия требуют соответствующих прав в исходном чате и не должны обходить Telegram-права.

---

# 22. Экономика — только базовые функции

Экономика в Lite-сборке намеренно ограничена основными сценариями.

`Баланс` / `Мой баланс` — личный баланс.

`Ириски` / `Монеты` — показать валюту.

`Бонус` / `Ежедневный бонус` / `Бонус дня` — получить ежедневный бонус с ограничением по времени.

`Передать ириски @user N` — перевести N ирисок.

`Подарить ириски @user N` — подарочный перевод.

`Топ ирисок` / `Топ балансов` / `Богачи` — рейтинг балансов.

Лиза проверяет баланс, цель перевода, запрет на самоперевод и наличие достаточного количества валюты.

---

# 23. Наследование

Эти команды относятся к сохранённой административной логике текущей сборки.

`+Завещание текст` / `+Наследство текст` — создать/настроить завещательную запись.

`Моё завещание` / `Моё наследство` — показать собственную запись.

`-Завещание` / `-Наследство` — удалить.

`Вступить в наследство ...` / `Принять наследство ...` — выполнить действие наследования по доступному сценарию.

`Наследодатель` — информация о владельце записи.

Лиза проверяет владельца, существование записи и допустимость операции.

---

# 24. Служебная информация

`Чат ИД` — ID текущего чата.

`Код чата` / `Код беседы` — внутренний идентификатор/код.

`СМС ИД` — ID текущего сообщения.

`Перейти к СМС N` — построить ссылку на сообщение, если Telegram-формат чата позволяет это сделать.

`Кто меня добавил` — определить, кто добавил пользователя, когда Telegram предоставляет эту информацию.

`Кто добавил @user` — запросить информацию о пригласившем, если она доступна.

`Инвайты` / `Инвайты чат` / `Кто приглашал` — информация по приглашениям.

---

# 25. AI и обращение к Лизе

В личном чате Лиза может отвечать без специального обращения.

В группе прямой AI-ответ активируется, когда сообщение адресовано Лизе, является ответом на сообщение Лизы или попадает под разрешённый сценарий.

Примеры:

```text
Лиза, объясни это
Лиза, помоги придумать название
@liza ...
```

Для AI нужен `OPENROUTER_KEY`. Если ключ не задан или сервис недоступен, Лиза должна сообщить об этом, а не выдавать видимость успешного AI-запроса.

---

# 26. Стикеры, триггеры и реакции

Лиза поддерживает локальные триггеры и обработку отдельных типов сообщений, включая стикеры/анимации, если соответствующая настройка включена.

Триггеры не должны мешать обычным командам: команда сначала распознаётся как команда, а автоматические реакции применяются только после прохождения основных проверок.

---

# 27. Права и безопасность выполнения

Для каждой административной команды Лиза должна пройти следующие проверки:

1. пользователь существует и является участником;
2. цель действия существует;
3. вызывающий имеет необходимый локальный ранг;
4. у Лизы есть соответствующее Telegram-разрешение;
5. цель не является защищённым создателем, если действие запрещено;
6. аргументы и сроки корректны;
7. изменение записывается в локальную базу/историю, если для команды предусмотрен журнал;
8. пользователю возвращается понятный результат и подсказка следующего шага при ошибке.

---

# 28. Формат ошибок и подсказок

Лиза не должна отвечать бессмысленным «ошибка».

Хороший ответ содержит:

- **что произошло**;
- **почему команда не выполнилась**;
- **что нужно изменить**;
- **пример правильной команды**.

Например, вместо `Неверно`:

```text
⚠️ Не удалось выдать мут.

Причина: не указан срок.

Пример:
Мут @username 30м

Можно использовать: 10м, 2ч, 1д.
```

---

# 29. Хранение данных

Основные данные Лизы хранятся локально в базе/хранилище проекта. Настройки должны быть привязаны к ID чата, а пользовательские данные — к ID Telegram-пользователя.

Локальные данные не должны подменять Telegram-состояние там, где требуется фактическое право Telegram. Например, локальный ранг не даёт возможности удалить сообщение, если у Лизы нет `can_delete_messages`.

---

# 30. Что намеренно отсутствует в Lite

Из Lite-версии удалены второстепенные игровые и социальные механики, которые перегружали бота и не относятся к основному назначению чат-менеджера: сложные игры, кланы/круги, брачные развлечения, расширенные VIP-механики, розыгрыши, закладки, многочисленные коллекционные функции и другие необязательные системы.

Цель Lite — **надёжная модерация, настройки, безопасность, статистика, профиль и базовая экономика**, а не максимальное количество команд.

---

# 31. Принцип совместимости

Команды, имеющие несколько вариантов написания, сохраняют привычные Iris-style формы там, где они реализованы. Новые пользователи могут использовать русские естественные формы (`Бан`, `Мут`, `Правила`, `Настройки`), а опытные — короткие варианты с `!`, `.`, `/`.

Если команда не выполняется, сначала используйте соответствующую команду `Помощь ...`: Лиза должна показывать синтаксис и пример, а не заставлять пользователя угадывать параметры.
