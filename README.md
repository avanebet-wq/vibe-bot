# Claude Pocket

Android-приложение, которое **одной кнопкой** ставит и запускает [Claude Code](https://claude.com/claude-code)
прямо на телефоне. Не нужны Termux и другие приложения — всё внутри.

## Как пользоваться

1. Скачай `claude-pocket.apk` со страницы **Releases** этого репозитория и установи
   (Android попросит разрешить установку из браузера).
2. Открой приложение и нажми **«Установить всё»**. Нужны интернет и ~1 ГБ места, 5–15 минут;
   не блокируй экран и не закрывай приложение.
3. Когда установка закончится, откроется экран входа: нажми «Открыть страницу входа», авторизуйся
   в браузере, скопируй код и вставь его в поле — нажми «Войти».
4. Дальше — обычный чат: пиши, что нужно сделать. Claude показывает свои действия карточками
   («Создаёт файл…», «Выполняет команду…») и спрашивает разрешения кнопками «Разрешить / Отклонить».
   Файлы создаются в папке `~/work`. Меню ⋮ в чате: новый чат, режим разрешений, терминал, переустановка.
5. Для опытных есть полноценный терминал (⋮ → «Терминал») с Ubuntu 24.04: `apt install …`, `git`, `python3`.

Меню ⋮ терминала (последняя кнопка нижней панели): вставка, открытие ссылки, размер шрифта, доступ к памяти
телефона (папка `/sdcard` внутри Linux), новая сессия, переустановка. Щипок двумя пальцами меняет шрифт.

## Как это устроено

- `libproot.so` — [PRoot для Android](https://github.com/termux/proot)
  (запускает Linux без root-прав; сборка из пакетов Termux вместе с libtalloc и libandroid-shmem), лежит в `jniLibs`, поэтому Android разрешает его выполнять.
- «Установить всё» скачивает `ubuntu-base` (arm64) с cdimage.ubuntu.com, проверяет SHA-256,
  распаковывает в `files/rootfs` и запускает `assets/setup.sh` внутри Ubuntu: пакеты + официальный
  установщик Claude Code (`curl -fsSL https://claude.ai/install.sh | bash`).
- Чат запускает `claude -p --input-format stream-json --output-format stream-json --permission-prompt-tool stdio`:
  ответы приходят потоком, а запросы разрешений — как данные, на которые отвечают кнопки.
- Терминал — библиотеки `terminal-view`/`terminal-emulator` из Termux (Apache 2.0).
- `targetSdk = 28` намеренно (как у Termux): с targetSdk ≥ 29 Android запрещает исполнять файлы
  из папки данных приложения. Поэтому приложение не подходит для Google Play — только установка из APK.
- Foreground-служба не даёт Android выгрузить процесс, пока идёт установка или открыта сессия.

## Ограничения

- Только 64-битные ARM-телефоны (arm64-v8a).
- proot медленнее настоящего Linux; тяжёлые сборки на телефоне будут долгими.
- APK подписан ключом `app/debug.keystore`, лежащим в репозитории: это личная сборка для установки
  вручную, не используй этот ключ для публикации.

## Сборка

GitHub Actions собирает APK при каждом push (`.github/workflows/build-apk.yml`).
Локально: `ANDROID_HOME=/путь/к/sdk ./gradlew assembleRelease` → `app/build/outputs/apk/release/`.
